# HTML-CSS-Scrimba

Practice files from a Scrimba HTML and CSS course: basic HTML elements, the box model (margin, padding, borders), Flexbox centering, a first look at CSS Grid, and a few small styled pages built along the way.

## Contents

| Path | What it covers |
| --- | --- |
| `11-August-2026/first.html` | First HTML page: an `h1` quote with an `h2` attribution. |
| `11-August-2026/list.html` | Unordered list of countries. |
| `11-August-2026/article.html` | News-style article ("Humans Have Reached Mars") with headings, a paragraph and a full-width image. |
| `11-August-2026/welcome.html` | Sign-up form elements: text inputs, a button and a file input. |
| `11-August-2026/google/` | Google homepage clone: centered logo, rounded search field and two buttons laid out with Flexbox. |
| `12-August-2026/paddingPractice.html` + `padding.css` | Padding, margin, border and border-radius on a text card and a pill-shaped "Following" button. |
| `12-August-2026/BusinessCard/` | Personal business card: photo beside name, title and location in a Flexbox card with a colored bottom border. |
| `12-August-2026/SpaceExploration/` | "Join the exploration" landing page with an animated GIF background, Google Font (Orbitron) and underlined heading. |
| `12-August-2026/GiftApp/` | Birthday page with a round profile photo and four gift boxes that swap to a GIF on hover (`:hover` + `background-image`). |
| `Grids/` | CSS Grid basics: four boxes in a two-column grid with `gap`. |

## How to run

No build step. Open any `.html` file directly in a browser. Some pages load images, GIFs and Google Fonts from the internet, so they need a connection to look complete.

## Tech

- HTML5
- CSS3 (box model, Flexbox, Grid, `:hover`, background images, Google Fonts)
